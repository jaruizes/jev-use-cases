Only future executions use updated rates. Previous cost estimates are not recalculated. Default Haiku 5.5 pricing applies to prompts up to 100k input tokens; the official higher tier is automatically used for longer prompts while the source rate remains unchanged. Edited rates override that default rule. Cached input, batch discounts and actual invoicing are not included.
